# مجلدات أغاني اللعبة

police/ : ملفات MP3 للدور الشرطي، مثل الأغاني الوطنية التي لديك حق استخدامها.
uber/ : ملفات MP3 لدور سائق أوبر.

استخدم أي أسماء للملفات، بما فيها العربية. لا يوجد مشغل ظاهر: تبدأ الأغاني في الخلفية ويختارها النظام بترتيب عشوائي لكل دور. لا يكرر آخر أغنية عند تبديل دورة القائمة إذا وُجد أكثر من ملف. يتوقف الصوت أثناء مشاهد الفيديو والإيقاف وينخفض مع السرينة.

شغّل محليًا عبر python music-library.py --serve (أو python tools/music-library.py --serve داخل المشروع). يكتشف الملفات الجديدة تلقائيًا خلال 30 ثانية؛ إعادة التحميل تفحصها فورًا. لا تغيّر اسم مجلدي police وuber.

عند نشر الموقع، أعد البناء والنشر بعد تغيير الملفات لإنشاء playlist.json تلقائيًا. لا تقرأ نسخة الإنترنت مجلدات جهاز اللاعب. لا يلزم تعديل JavaScript.

تسجيل «اسلمي يا مصر» التاريخي هو التسجيل المتاح حاليًا. أضف الأغاني الأخرى من مصادر تسمح لك باستخدامها.
