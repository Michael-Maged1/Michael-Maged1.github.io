لا تغيّر أسماء الملفات أو المجلد. استبدل الفيديو المطلوب بنفس الاسم، ويمكن رفع الجودة كما تريد. أضف station-first.mp4 عندما يصبح جاهزًا؛ تكتشفه اللعبة تلقائيًا عند إعادة التحميل، وتستخدم المشهد داخل اللعبة إذا لم يوجد.

يفضل MP4 بترميز H.264 مع صوت AAC، وأبعاد أفقية 16:9 ومدة لا تزيد عن 10 ثوانٍ. التشغيل بملء الشاشة. أعد تحميل الصفحة بعد الاستبدال؛ عند تحديث الموقع المنشور يجب نشر الملفات المحدّثة أيضًا.

محليًا: فك police-videos.zip بجوار ملف اللعبة مع الحفاظ على هذا المسار، وشغّل عبر خادم HTTP. لا يتطلب استبدال الفيديو أي تغيير في JavaScript أو إعادة بناء اللعبة.
